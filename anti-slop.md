# Anti-slop global

Proibições que valem para todo projeto, salvo quando o design system do projeto
determinar o contrário (ver `projetos/<projeto>/brief.md`).

## Tipografia

- Proibido: Inter, Roboto, Arial, Helvetica e fontes padrão de sistema como fonte titular.
- Proibido: uma única fonte para tudo, sem contraste de papel entre título e corpo.
- Proibido: texto cinza sobre fundo colorido.

## Cor

- Proibido: preto puro (#000) e cinzas neutros sem temperatura. Todo neutro leva tinta.
- Proibido: degradê roxo-para-azul como fundo genérico de hero.
  - **Exceção documentada:** projeto cujo brand guide oficial exige degradê azul-roxo. O design system do cliente vence.
- Proibido: paleta escolhida sem justificativa escrita de por que aquela e não outra.

## Layout e espaço

- Proibido: card dentro de card.
- Proibido: envolver toda seção em card só para "organizar".
- Proibido: grid de 3 cards idênticos como solução padrão de qualquer seção.
- Proibido: ícone dentro de quadradinho arredondado acima de cada título de seção.
- Proibido: espaçamento uniforme em tudo. Hierarquia precisa aparecer no respiro.

## Movimento

- Proibido: easing com bounce ou elástico.
- Proibido: animação em elemento que não ganha nada com ela.
- Proibido: fade-in genérico em todas as seções ao rolar.

## Texto de interface

- Proibido: "Bem-vindo", "Transforme seu negócio", "Simples assim", "Elevate", e
  qualquer headline que serviria para qualquer empresa.
- Proibido: emoji como ícone de produto.

## Nota de origem
